# Тестирование сайта ЦКБ «БИБКОМ» (ckbib.ru)

Стратегия, тест-план, 20 тест-кейсов, автотесты на Playwright, щадящий нагрузочный тест и отчёт по 14 багам.

- **Отчёт:** `ЦКБ_БИБКОМ_Стратегия_Тест-план_Тест-кейсы_Баги.docx`
- **Автотесты:** `tests/` — Page Object `ckbib.page.ts`, 16 UI-тестов (`ui.spec.ts`), 4 HTTP-теста (`http.spec.ts`). ID теста совпадает с ID тест-кейса в отчёте.
- **Нагрузочный тест:** `load/load-test.mjs` (autocannon, 1 → 5 → 10 соединений по 20 с), результаты в `load/results.json`
- **Скриншоты багов:** `img/`

## Запуск

Из папки `qa-ckbib`:

```bash
npm install
npx playwright install chromium
npm test          # 20 автотестов: 7 проходят, 13 падают — каждый упавший = найденный баг
npm run report    # HTML-отчёт со скриншотами падений
npm run load      # нагрузочный тест (~2 минуты)
```

Нагрузку выше 10 соединений на сайт не даём: это чужой рабочий сайт.
